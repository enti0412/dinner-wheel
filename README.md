# 晚餐转盘 (Dinner Wheel) 🎡

[![GitHub Pages](https://img.shields.io/badge/Deployed%20on-GitHub%20Pages-blue)](https://enti0412.github.io/dinner-wheel/)

## 🌟 项目简介
这是一个基于原生 JavaScript 开发的交互式转盘工具。通过 AI 协作开发，实现了流畅的动画效果和精准的逻辑判定，旨在通过趣味性的方式帮助用户做决定。

## ✨ 主要特性
- **实时更新**：添加新食物后，转盘扇区实时平分，无需刷新。
- **用户友好**：
  - 🚩 红色指针指向下方，视觉更直观。
  - 📖 文字水平排列，无需歪头即可阅读。
- **完全随机**：模拟真实物理减速逻辑。

## 🛠️ 技术栈
- **HTML5 Canvas**: 用于绘制旋转动画。
- **CSS3**: 卡片式 UI 设计。
- **JavaScript**: 物理减速算法与交互逻辑。

## 🚀 预览与使用
1. 访问部署地址：[https://enti0412.github.io/dinner-wheel/]
2. 在下方输入框输入菜品，点击“添加”。
3. 点击“开始转盘”，等待美食降临！
